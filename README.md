# VEILINK 六轴机械臂入门指南

VEILINK 是一款以 3D 打印结构件和飞特 STS3215 总线舵机为基础的六轴机械臂。本仓库提供 3D 模型、装配说明、运动学参数，以及从舵机编号、整机校准到单关节调试的完整入门资料。

项目展示与打印配置可参考：[MakerWorld：VEILINK 六轴机械臂](https://makerworld.com.cn/zh/models/2817152-veilink-liu-zhou-ji-jie-bi#profileId-3285755)。

> 本项目涉及外部电源和可运动机械结构。操作前请完整阅读安全说明。出现异常运动、发热、异味、异响、线缆发烫或结构干涉时，应立即卸力并切断舵机电源。

## 一、准备材料与工具

装配说明书中的参考物料如下：

| 材料 | 数量 | 说明 |
| --- | ---: | --- |
| 飞特 STS3215 C001 7.4 V 总线舵机 | 7 | 六个旋转关节及一个夹爪 |
| 微雪总线舵机驱动板 | 1 | 连接电脑与舵机总线 |
| 3～12 V 可调电源 | 1 | 按舵机铭牌要求设置输出电压 |
| USB Type-C 数据线 | 1 | 必须支持数据传输 |
| 3D 打印件 | 15 | 使用仓库中的 3MF 文件打印 |

建议准备十字螺丝刀、尖嘴钳和剪钳。紧固件用途：M2 螺丝用于固定舵机，M2.5 螺丝仅用于固定控制板，M3 螺丝用于固定舵盘及连接 3D 打印件。具体方向和安装顺序请以[装配说明书](<3D Models/装配说明书 Assembly Instruction.pdf>)为准。

### 供电与接线安全

1. STS3215 有不同电压版本，通电前必须核对舵机铭牌，不能只根据系列名称判断电压。
2. 舵机必须使用符合规格且容量足够的外部电源；USB 主要用于通信，不要依靠 USB 为多台舵机供电。
3. 确认 VCC、GND、TTL 信号线方向正确，并确保控制板和舵机电源共地。
4. 接线、拔线或更换舵机前先关闭舵机电源，禁止带电插拔 TTL 总线插头。
5. J2、J3 等承重关节卸力时会下坠，调试时必须使用支架、吊带或由另一人托住机械臂。

## 二、安装软件环境

快速入门 Notebook 按 LeRobot 0.5.x API 编写，仓库中的校准记录使用 LeRobot 0.5.1。为减少版本差异，建议为本项目创建独立环境。

以下示例适用于 Windows PowerShell，并以 Python 3.10 为例：

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install "lerobot==0.5.1" pyserial ipykernel ipywidgets jupyter
python -m ipykernel install --user --name lerobot --display-name "Python (lerobot)"
```

随后使用 VS Code 或 Jupyter 打开 `快速入门指南` 中的 Notebook，并选择 `Python (lerobot)` 内核。运行第一份 Notebook 的环境检查单元，确认 `lerobot`、`serial`、`serial.tools.list_ports` 和 `ipykernel` 均显示为 `OK`。

如果没有检测到串口，请检查：

- USB 线是否支持数据传输；
- Windows 设备管理器的“端口（COM 和 LPT）”中是否能看到控制板；
- 驱动是否正确安装；
- 是否有串口助手、其他 Notebook 或旧的 Python 内核占用了串口。

## 三、舵机编号与实体标记

在舵机装入机械臂之前，打开并按顺序运行 [1-舵机编号标记.ipynb](<快速入门指南/1-舵机编号标记.ipynb>)。

默认编号为：

| 关节 | 舵机 ID | 功能 |
| --- | ---: | --- |
| J1 | 1 | 基座回转 |
| J2 | 2 | 肩部俯仰 |
| J3 | 3 | 肘部俯仰 |
| J4 | 4 | 前臂回转 |
| J5 | 5 | 腕部俯仰 |
| J6 | 6 | 末端回转 |
| Gripper | 7 | 夹爪开合 |

编号时必须遵循以下流程：

1. 将 Notebook 中的 `PORT` 改成控制板的实际串口，例如 `COM3`。
2. 写入 ID 时，控制板上一次只能连接一台舵机，避免多个出厂 ID 相同的舵机发生通信冲突。
3. 依次将 `TARGET_JOINT` 设置为 `J1`～`J6`；使用电动夹爪时再设置 `gripper`。
4. 每台舵机写入并回读成功后立即断电，并粘贴 `J1-ID1` 等实体标签。
5. 所有舵机都完成编号后再串联总线，将 `RUN_FULL_BUS_VERIFY` 改为 `True`，确认每个规划 ID 均可正常通信。

这一阶段只设置舵机 ID 和通信波特率，不设置零位、方向和机械限位，也不会主动命令舵机转动。

## 四、打印与机械装配

1. 使用 [3MF 文件](<3D Models/VEILINK Arm 3D Print.3mf>)进行切片和打印；也可使用 [STEP 模型](<3D Models/VEILINK Arm.STEP>)查看或修改结构。
2. 打印件完全冷却后再拆除支撑，清理毛边和孔内残料；必要时先试装螺丝。
3. 再次核对每台舵机的 ID 标签和对应关节位置，然后按照[装配说明书](<3D Models/装配说明书 Assembly Instruction.pdf>)中的方向安装舵机和舵盘。
4. 按说明书顺序完成 J1～J7、控制板和连杆装配。说明书给出的预计装配时间约为 20 分钟，不包含打印和舵机编号时间。
5. 整理线缆并预留关节运动余量。J1、J4、J6 即使允许单圈旋转，也不能忽略外部线缆缠绕风险。

舵机编号错误、舵盘方向错误或关节安装位置错误，都可能导致运动方向异常或机械碰撞；首次通电前应逐项复核。

## 五、零位与限位校准

机械装配完成后，打开 [2-舵机校准.ipynb](<快速入门指南/2-舵机校准.ipynb>)。

校准流程包括：

1. 连接全部规划 ID，并立即关闭所有舵机扭矩；
2. 将机械臂摆到[零位示意图](<运动学参数 Kinematic Parameters/零位 Zero Pose.PNG>)所示的设计零位；
3. 记录 J1～J6 和夹爪的编码器零位及 Homing Offset；
4. 在机械臂受到可靠支撑的情况下，手动采集 J2、J3、J5 和夹爪的机械安全范围；
5. 程序在测量端点内侧增加安全裕量，并生成软件限位；
6. 汇总检查通过后，将结果保存到 [机械臂校准参数.json](<快速入门指南/机械臂校准参数.json>)。

J1、J4、J6 按编码器单圈 360°关节处理；J2、J3、J5 和夹爪需要手动采集限位。编码器零位不等于标准 DH 模型中的固定角偏置，两者需要分别确认。

> 仓库中的 JSON 是一台实际机械臂的校准记录，只能作为数据结构和参考示例。舵机安装角度、机械误差和安全范围会因设备而异，每台新装机械臂都必须重新校准。后续控制程序应在 `calibrated` 不为 `true` 时拒绝使能扭矩。

## 六、单关节调试

校准完成后，打开 [3-单舵机控制.ipynb](<快速入门指南/3-单舵机控制.ipynb>)。程序会从校准 JSON 加载舵机 ID、零位和软限位，并为 J1～J6 和夹爪创建独立控制面板。

推荐逐关节执行：

1. 固定机械臂并托住相关连杆，首次测试不要安装负载；
2. 点击“读取状态”，检查位置、电压、温度和电流反馈；
3. 点击“使能/保持”，确认关节没有明显跳动；
4. 将目标只改变 2°～5°，夹爪只改变 2%～5%；
5. 点击“移动到目标”，确认方向、零位和限位正确；
6. 确认正常后再逐步扩大范围，不要首次测试就运动到限位；
7. 测试结束后点击“卸力”，最后运行断开单元再关闭舵机电源。

滑块本身不会立即发送运动命令。只有对应关节已经“使能/保持”，并再次点击“移动到目标”后，程序才会发送位置指令。遇到异常时立即点击“全部紧急卸力”并切断电源。

## 七、常见问题

### 找不到控制板或舵机

检查外部电源、插头方向、共地、USB 数据线、串口驱动和串口占用情况。若整条总线中只有一个 ID 掉线，应断电后将该舵机单独连接，并用编号 Notebook 验证。

### 舵机写入 ID 后无法重新连接

断电重启舵机，确保总线上只连接这一台，再使用相同目标关节重新回读。不要在不确定时猜测原始 ID 或波特率。

### 使能时关节明显跳动或方向错误

立即卸力并断电，检查舵机 ID、零位、舵盘安装方向、参数文件中的 `direction`，以及是否有其他程序同时控制串口。

### 校准范围跨越 0/4095

对于 J2、J3、J5 等有限关节，这通常说明零位没有处于编码器合理区间。应检查舵盘安装并重新执行零位和限位校准。

### 控制面板不显示

确认在 VS Code 或 Jupyter 中运行 Notebook，选择了 `Python (lerobot)` 内核，并已安装 `ipywidgets`。重新启动内核后从头运行全部单元。

### 温度、电流持续升高或出现异响

立即卸力并断电，检查机械干涉、负载、供电电压、线缆和舵机保护参数。不要通过增大速度或扭矩来强行克服结构卡滞。

## 推荐调试顺序

请严格按照以下顺序进行：

```text
准备材料与打印件
        ↓
安装软件环境并确认串口
        ↓
逐台设置舵机 ID 并粘贴标签
        ↓
按照装配说明完成机械装配与接线
        ↓
记录零位并采集安全限位
        ↓
逐关节进行小幅、低速测试
        ↓
确认方向、零位和限位后再进行上层控制开发
```

首次调试时，安全优先于速度。任何一步出现异常，都应先卸力、断电并回到上一步检查。
