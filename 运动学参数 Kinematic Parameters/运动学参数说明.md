# VEILINK 六轴机械臂运动学参数说明

本文面向第一次接触机械臂运动学的读者，说明 VEILINK 六轴机械臂的零位、关节方向、标准 DH 参数以及如何用这些参数计算工具中心点（TCP）的位置和姿态。

> 本文中的长度单位均为 **mm**，角度单位均为 **°**。编程计算三角函数前，必须把角度转换为弧度。

## 1. 先认识这台机械臂

VEILINK 机械臂由 6 个旋转关节组成：

- **J1～J3** 主要决定手腕中心在空间中的位置；
- **J4～J6** 主要调整末端执行器的姿态；
- 夹爪开合是独立动作，不计入机械臂的 6 个位姿自由度，也不在本 DH 参数表中。

机械臂的完整“位姿”包含两部分：

- **位置**：TCP 在基座坐标系中的 `x、y、z` 坐标；
- **姿态**：末端坐标系相对于基座坐标系的朝向。

因此，六轴机械臂通常可以同时控制 TCP 的 3 个位置自由度和 3 个姿态自由度。

## 2. 零位、TCP 与坐标方向

### 2.1 什么是机械零位

本文把下列状态定义为机械臂零位：

```text
q = [q1, q2, q3, q4, q5, q6] = [0°, 0°, 0°, 0°, 0°, 0°]
```

此时机械臂外形如零位图所示，主体连杆大致竖直向上。零位是描述所有关节角的共同参考，不代表舵机原始编码值一定为 0。实际控制时，必须通过校准把舵机编码值换算为本文中的关节角 `qi`。

### 2.2 什么是 TCP

**TCP（Tool Center Point，工具中心点）** 是控制末端工具时使用的参考点。本文模型把 TCP 放在夹爪顶部中心线上。若以后更换夹爪、吸盘或其他工具，应重新测量工具长度，并在第 6 关节之后增加相应的工具变换。

在图示零位中：

- 地面到 TCP 的总高度为 **514 mm**；
- TCP 位于机械臂中心线上；
- 夹爪开合轴位于 TCP 下方 **80 mm**。

### 2.3 图中的箭头和圆点符号

- **红色箭头**：关节正轴 `+z(i-1)`；关节正转遵循右手定则；
- **蓝色符号**：对应 DH 坐标系的正 `+x(i-1)` 方向；
- `⊙`：方向垂直纸面向外；
- `⊗`：方向垂直纸面向内。

右手定则可以这样理解：右手拇指指向关节正轴，其余四指弯曲的方向就是关节角增大的方向。

> 不能只根据屏幕上“顺时针/逆时针”判断正负方向。观察视角改变后，视觉上的旋转方向也会改变；关节正方向应始终由轴向和右手定则确定。

### 2.4 零位图中的主要尺寸

从地面沿竖直方向到 TCP，各段尺寸依次为：

| 区段 | 尺寸（mm） | 说明 |
| --- | ---: | --- |
| 地面到 J1 轴 | 42 | 基座高度的一部分 |
| J1 轴到 J2 轴 | 22 | 与上一段合计得到 `-d1 = 64` |
| J2 轴到 J3 轴 | 120 | 对应 `a2 = 120` |
| J3 轴到 J4 轴 | 130 | 前臂下段尺寸 |
| J4 轴到 J5 轴 | 41 | 与上一段合计得到 `-d4 = 171` |
| J5 轴到 J6 附近参考面 | 60 | 腕部/末端结构尺寸的一部分 |
| 参考面到夹爪开合轴 | 19 | 与相邻尺寸共同构成末端偏距 |
| 夹爪开合轴到 TCP | 80 | 夹爪工具长度 |
| **合计** | **514** | 零位总高度 |

这里出现负的 `d1、d4、d6`，不是长度为负，而是因为相应位移方向与所定义坐标轴正方向相反。

## 3. 标准 DH 参数是什么

DH（Denavit–Hartenberg）方法用 4 个参数描述相邻两节连杆坐标系之间的关系。本文采用的是 **标准 DH（Standard DH）**，约定：

> `z(i-1)` 轴与关节 `Ji` 的旋转轴重合。

每一行 DH 参数包含：

| 参数 | 中文名称 | 对旋转关节的含义 |
| --- | --- | --- |
| `θi` | 关节角 | 绕 `z(i-1)` 旋转的角度；本机械臂的变量项来自 `qi` |
| `di` | 连杆偏距 | 沿 `z(i-1)` 平移的距离 |
| `ai` | 连杆长度 | 沿 `xi` 平移的距离 |
| `αi` | 连杆扭角 | 绕 `xi` 旋转，使 `z(i-1)` 转向 `zi` 的角度 |

对于第 `i` 个关节，从坐标系 `{i-1}` 到 `{i}` 的标准 DH 变换为：

```text
^(i-1)Ti = Rz(θi) · Tz(di) · Tx(ai) · Rx(αi)
```

展开成齐次变换矩阵：

```text
             ┌ cosθ  -sinθ·cosα   sinθ·sinα   a·cosθ ┐
^(i-1)Ti  =  │ sinθ   cosθ·cosα  -cosθ·sinα   a·sinθ │
             │   0       sinα         cosα        d   │
             └   0         0            0         1   ┘
```

矩阵左上角 `3×3` 部分表示姿态，最右侧前三个数表示位置。

> “标准 DH”和“改进 DH（Modified DH）”的坐标系附着方式及变换顺序不同。本文参数不能直接代入改进 DH 公式。

## 4. 本机械臂的 DH 参数

| 关节 | DH 关节变量 `θi` | `di`（mm） | `ai`（mm） | `αi` | `qi` 最小值 | `qi` 最大值 | 主要功能 |
| ---: | --- | ---: | ---: | ---: | ---: | ---: | --- |
| J1 | `q1` | -64 | 0 | -90° | -180° | 180° | 基座回转 |
| J2 | `q2 + 90°` | 0 | 120 | 180° | -87° | 87° | 肩部俯仰 |
| J3 | `q3 + 90°` | 0 | 0 | -90° | -155° | 155° | 肘部俯仰 |
| J4 | `q4 + 180°` | -171 | 0 | 90° | -180° | 180° | 前臂回转 |
| J5 | `q5` | 0 | 0 | -90° | -101° | 101° | 腕部俯仰 |
| J6 | `q6` | -159 | 0 | 0° | 0° | 360° | 末端回转至 TCP |

### 4.1 `qi` 与 `θi` 不完全相同

`qi` 是以机械零位为 0° 的实际关节变量，`θi` 是代入 DH 变换矩阵的角度。两者关系为：

```text
θ1 = q1
θ2 = q2 + 90°
θ3 = q3 + 90°
θ4 = q4 + 180°
θ5 = q5
θ6 = q6
```

`+90°` 或 `+180°` 是由 DH 坐标系定义产生的固定补偿，并不表示机械臂回到零位时还要命令舵机额外旋转这些角度。

### 4.2 为什么只有 `a2` 不为 0

`ai` 表示两根相邻关节轴之间沿公共法线的距离。这个模型中，J2 与 J3 之间存在 **120 mm** 的公共法线距离，因此 `a2=120 mm`；其余相邻轴在各自 DH 建系下相交或共线，所以相应 `ai=0`。

### 4.3 `d4` 和 `d6` 包含哪些实体尺寸

- `-d4=171 mm`，对应图中 `130+41 mm`；
- `-d6=159 mm`，对应图中 `60+19+80 mm`，其终点为 TCP；
- `-d1=64 mm`，对应图中 `42+22 mm`。

这些是用于坐标变换的等效几何尺寸，不要求每个 DH 参数只对应一根独立的实体连杆。

## 5. 六个关节逐一说明

### 5.1 J1：基座回转（Base Rotation）

- **作用**：带动 J2～J6 和末端工具绕基座轴整体旋转，主要改变 TCP 的水平朝向；
- **关节变量**：`θ1=q1`；
- **范围**：`-180° ≤ q1 ≤ 180°`；
- **零位轴向**：正轴沿图中的红色 `+z0`；
- **直观理解**：类似人站在原地转身；
- **注意**：当 TCP 位于基座轴线上时，仅从 TCP 位置可能无法唯一确定 J1，姿态或前一时刻关节角也要参与选解。

### 5.2 J2：肩部俯仰（Shoulder Pitch）

- **作用**：抬起或放下整条手臂，对 TCP 的伸出距离和高度影响很大；
- **关节变量**：`θ2=q2+90°`；
- **范围**：`-87° ≤ q2 ≤ 87°`；
- **几何参数**：`a2=120 mm`；
- **直观理解**：类似人的肩膀带动上臂前后摆动；
- **注意**：接近上下限时应预留减速和机械安全余量，不应把表中理论边界直接当作高速运动边界。

### 5.3 J3：肘部俯仰（Elbow Pitch）

- **作用**：改变手臂弯曲程度，与 J2 配合决定“肘上/肘下”等不同构型；
- **关节变量**：`θ3=q3+90°`；
- **范围**：`-155° ≤ q3 ≤ 155°`；
- **直观理解**：类似人的肘关节屈伸；
- **注意**：同一个 TCP 目标可能有多组 J2/J3 解，逆运动学时要根据限位、避障和与当前姿态的距离选解。

### 5.4 J4：前臂回转（Forearm Rotation）

- **作用**：使腕部绕前臂方向滚转，主要改变末端姿态；
- **关节变量**：`θ4=q4+180°`；
- **范围**：`-180° ≤ q4 ≤ 180°`；
- **几何参数**：`d4=-171 mm`；
- **直观理解**：类似人的前臂旋前/旋后；
- **注意**：固定补偿 `+180°` 只在运动学计算中加入，不能重复加入舵机命令。

### 5.5 J5：腕部俯仰（Wrist Pitch）

- **作用**：使末端工具抬头或低头，是调整夹爪朝向的关键关节；
- **关节变量**：`θ5=q5`；
- **范围**：`-101° ≤ q5 ≤ 101°`；
- **直观理解**：类似手腕上下弯曲；
- **注意**：在 `q5` 接近某些轴线重合构型（特别是零附近）时，J4 与 J6 对姿态的作用可能耦合，属于腕部奇异附近，应避免用很大的关节速度追踪微小姿态变化。

### 5.6 J6：末端回转（End Rotation）

- **作用**：使夹爪绕末端中心轴旋转；
- **关节变量**：`θ6=q6`；
- **范围**：`0° ≤ q6 ≤ 360°`；
- **几何参数**：`d6=-159 mm`，从腕部坐标系延伸到 TCP；
- **直观理解**：类似拧动螺丝刀；
- **注意**：0° 与 360° 的几何姿态相同，但控制器数值可能不同。轨迹规划应采用连续角度或最短角差，避免在边界处突然反转一整圈。

### 5.7 夹爪开合轴（Gripper Axis）

夹爪开合只改变两指间距，不改变本文定义的 TCP 坐标系，因此没有单独的 DH 行。若抓取物体后希望把抓取点而不是夹爪顶部中心作为 TCP，应增加一个工具坐标系，并写出从当前 TCP 到新工具点的固定变换。

## 6. 如何计算正运动学

正运动学解决的问题是：**已知六个关节角，求 TCP 的位置和姿态。**

计算步骤：

1. 输入机械零位定义下的 `q1～q6`；
2. 检查每个 `qi` 是否在关节范围内；
3. 按上文关系计算 `θ1～θ6`；
4. 将每行的 `θi、di、ai、αi` 代入标准 DH 矩阵，得到 `^(i-1)Ti`；
5. 按关节顺序左乘：

```text
^0T6 = ^0T1 · ^1T2 · ^2T3 · ^3T4 · ^4T5 · ^5T6
```

最终矩阵写作：

```text
       ┌ r11 r12 r13 px ┐
^0T6 = │ r21 r22 r23 py │
       │ r31 r32 r33 pz │
       └  0   0   0   1 │
```

- `p=[px,py,pz]ᵀ` 是 TCP 在基座坐标系中的位置；
- `R`（左上角 `3×3`）是 TCP 的姿态旋转矩阵。

### 6.1 可直接参考的 Python 实现

```python
import numpy as np


def dh_standard(theta_deg, d_mm, a_mm, alpha_deg):
    """返回标准 DH 齐次变换矩阵。"""
    theta = np.deg2rad(theta_deg)
    alpha = np.deg2rad(alpha_deg)
    ct, st = np.cos(theta), np.sin(theta)
    ca, sa = np.cos(alpha), np.sin(alpha)

    return np.array([
        [ct, -st * ca,  st * sa, a_mm * ct],
        [st,  ct * ca, -ct * sa, a_mm * st],
        [0.0,      sa,       ca,       d_mm],
        [0.0,     0.0,      0.0,        1.0],
    ])


def forward_kinematics(q_deg):
    """q_deg: [q1, q2, q3, q4, q5, q6]，单位为度。"""
    q = np.asarray(q_deg, dtype=float)
    if q.shape != (6,):
        raise ValueError("q_deg 必须包含 6 个关节角")

    q_min = np.array([-180, -87, -155, -180, -101,   0], dtype=float)
    q_max = np.array([ 180,  87,  155,  180,  101, 360], dtype=float)
    if np.any(q < q_min) or np.any(q > q_max):
        raise ValueError("存在超出 DH 参数表范围的关节角")

    theta = q + np.array([0, 90, 90, 180, 0, 0], dtype=float)
    d = np.array([-64, 0, 0, -171, 0, -159], dtype=float)
    a = np.array([0, 120, 0, 0, 0, 0], dtype=float)
    alpha = np.array([-90, 180, -90, 90, -90, 0], dtype=float)

    T = np.eye(4)
    for values in zip(theta, d, a, alpha):
        T = T @ dh_standard(*values)
    return T


T_0_tcp = forward_kinematics([0, 0, 0, 0, 0, 0])
print(T_0_tcp)
print("TCP position (mm):", T_0_tcp[:3, 3])
```

### 6.2 用零位做自检

将 `q=[0,0,0,0,0,0]°` 代入本文参数，理论结果为：

```text
         ┌ -1  0  0    0 ┐
^0Ttcp = │  0 -1  0    0 │
         │  0  0  1 -514 │
         └  0  0  0    1 ┘
```

这表示：

- TCP 位于基座中心线上；
- 沿本模型定义的基座 `+z0` 反方向移动 514 mm；
- 物理上对应图中的“从地面竖直向上 514 mm”；
- TCP 坐标系的 x、y 轴相对基座各反向，z 轴同向。

如果零位计算结果不是这个位置，优先检查：是否误用了改进 DH、矩阵相乘顺序是否颠倒、是否遗漏固定角补偿，以及角度是否正确转换为弧度。

## 7. 逆运动学、限位与奇异位形

逆运动学解决的问题是：**已知期望 TCP 位姿，求六个关节角。** 它通常比正运动学更复杂，原因包括：

- 同一目标位姿可能有多组关节解；
- 某些目标超出机械臂工作空间，没有可行解；
- 数学上存在的解可能超过关节限位或发生结构干涉；
- 奇异位形附近，末端的小变化可能需要很大的关节运动。

常见选解原则：

1. 先剔除超过各关节范围的解；
2. 再剔除会造成连杆、夹爪、桌面或环境碰撞的解；
3. 优先选择与当前关节角距离较小的连续解；
4. 给机械限位和奇异位形留出安全余量；
5. 在真实机械臂上先低速、单步、小幅度验证。

需要特别留意的构型包括：手臂接近完全伸直或折叠，以及腕部轴线接近重合。此时机械臂仍可能处在正常几何位置，但某些方向的运动能力下降，数值逆解也可能变得不稳定。

## 8. 从运动学角度到真实舵机指令

DH 模型中的 `qi` 与舵机内部位置值之间通常还隔着一层标定关系：

```text
舵机编码值 → 零位偏置修正 → 方向符号修正 → 关节角 qi → DH 角 θi
```

实际使用时应分别保存：

- 每个关节的舵机编号；
- 机械零位对应的编码值；
- 编码增大是否等于本文关节正方向；
- 实机测得的安全软限位；
- 编码值与角度之间的比例关系。

> DH 参数表中的角度范围用于运动学建模和规划参考，不能替代具体机械臂的实机校准、碰撞检查和安全软限位。

## 9. 初学者常见问题

### 为什么 `d` 可以是负数？

`d` 是带方向的坐标位移，不是物体的“负长度”。负号只表示位移方向与相应 z 轴正方向相反。

### 为什么零位时 `θ2、θ3、θ4` 不是 0°？

因为 `θi` 是 DH 坐标系之间的角度，而 `qi` 是以机械零位为基准的关节角。固定的 90° 或 180° 用于把两套定义对齐。

### 为什么 J6 的范围写成 0°～360°？

它表达一整圈可用范围。0° 与 360° 姿态等价，但规划连续轨迹时仍要处理数值跨界问题，并核对线缆是否允许连续回转。

### 只控制 TCP 位置，是否一定要用六个关节？

不一定。前三个关节通常承担主要定位任务，后三个关节主要负责姿态，但各关节并非完全独立。完整的空间位姿控制仍需联合求解六个关节。

### 更换夹爪后要重新做整套 DH 参数吗？

如果 J1～J6 的结构没有变化，通常不必修改前六行 DH 参数，只需重新定义从 J6 到新 TCP 的工具变换；若第 6 轴到安装面的结构尺寸也改变，则应同步更新相应末端偏距。

## 10. 建议的学习与验证顺序

1. 对照零位实物图识别 J1～J6 和夹爪轴；
2. 用右手定则逐个确认关节正方向；
3. 理解 `qi`、`θi` 与固定角补偿的区别；
4. 用零位验证正运动学结果和 514 mm 总高度；
5. 给单个关节增加少量角度，观察 TCP 位置和姿态的变化；
6. 加入关节限位、连续角度处理和碰撞检查；
7. 最后再学习数值逆运动学、雅可比矩阵和轨迹规划。

完成以上步骤后，就具备了使用本组参数进行正运动学验证、逆运动学开发和上层轨迹规划的基础。
